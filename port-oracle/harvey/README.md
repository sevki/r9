Verbatim copies of the Harvey OS files that the C oracle is built from, at
their original paths (https://github.com/Harvey-OS/harvey, branch `GPL-C11`,
commit 13e6f3c40bfa616f6b1c4b22952704729587385b). Nothing here is edited, so
the C is compiled against the same headers Harvey uses. They keep their
original UCB Plan 9 licence headers.

Only the files needed by the modules ported so far are here.
